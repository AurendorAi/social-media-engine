# Changelog

## 1.0.0

### Public plugin architecture
- Native Codex and Claude plugin manifests, GitHub marketplace definitions, and a small
  installable ZIP instead of a copied brand-specific application.
- Resumable brand onboarding, explicit owner approval, durable local memory and separate
  profiles for each brand.
- Self-contained editorial, creative production, review, publishing and learning guides.

### Workflow and safety
- Plans and platform/language variants bound to current brand context.
- Immutable revision history, independent-review records, owner approval and rated feedback.
- Deterministic caption constraints and approved scoped learning rules.
- Hash-checked identity/output assets, file-type checks and publication-rights declarations.
- Local review dashboard with responsive media previews and no public server exposure.
- Opt-in Postiz requests with exact account/time/content confirmation, durable receipts,
  ambiguity handling and no blind retries.
- Honest metric provenance and explicit limitations for unavailable providers/inbox data.

### Distribution
- English, Arabic and Japanese READMEs, MIT licensing, privacy/security guidance.
- Automated regression suite, isolated browser/media exercise and deterministic packaging.
- Legacy copied application retained only in an ignored local recovery archive.

Live account/host acceptance and genuine owner creative calibration are not implied by
this release's local tests. See docs/audit/SOCIAL-MEDIA-ENGINE-GAPS.md.
