## الإصدار 2.2: ذاكرة إبداعية مستقلة لكل علامة

أضفنا موجزًا إبداعيًا يُحفظ بعد موافقة المالك: موقف الجمهور، الوعد المدعوم بالأدلة، أمثلة النبرة، مبادئ التصميم، محاور المحتوى وما يجب تجنبه. يراجع المساعد المحتوى الحالي ويعرض عينات فعلية قبل التوسع، ثم يسترجع الاتجاه المعتمد في الجلسات التالية. تغيير الهوية أو الملاحظات المعتمدة أو ملفات العينات يستدعي مراجعة الاتجاه. تظهر الحالة في «Today» و«Brand & assets».

أضفنا خلاصة أصلية من دراسة 123 قالبًا كاملًا و302 صفحة، مع توثيق المصادر والاستبعادات. توقفت الدراسة بطلب المالك قبل بلوغ أهداف الألف قالب لكل أسلوب؛ لا ندّعي اكتمالها أو تدريب النموذج. لا تتضمن الحزمة تصاميم Canva أو بيانات العملاء أو هوية AURENDOR الخاصة.

الهدف نقل عمق العملية إلى كل علامة، مع بقاء جودة النتائج مرتبطة بالنموذج والأدوات والمراجعة الفعلية. راجع [توافق التطبيقات وأوامر التثبيت المختبرة](docs/HOST-COMPATIBILITY.md) و[منهج جودة العلامة](plugins/social-media-engine/skills/social-media-engine/references/brand-quality.md).

## الجديد في ٢٫٢٫١: الإبداع جزء من طريقة العمل الافتراضية

لا تحتاج إلى إضافة «كن أكثر إبداعًا» إلى طلب المنشور. يطوّر المساعد أفكارًا مختلفة،
ويختار الأنسب للجمهور والعلامة، ثم يبني الصورة والكتابة معًا ويفحص التصدير الفعلي
بالحجم الكامل وعلى الهاتف. تحافظ التعديلات البسيطة والسلاسل المعتمدة على اتجاهها.
راجع [منهج الإبداع الافتراضي](plugins/social-media-engine/skills/social-media-engine/references/creative-defaults.md).

ينقل التحديث طريقة التفكير وراء أمثلة محلية نالت استحسان المالك، ولا يوزّع صورها
الخاصة أو يحوّلها إلى قوالب موحّدة. يعمل المنهج عبر مدخل المهارة المشترك في Codex
وClaude؛ تبقى جودة التنفيذ مرتبطة بالنموذج والأدوات والمراجعة. لا توجد خطوة موافقة
إضافية أو ترحيل لبيانات مساحة العمل.

## الجديد في الإصدار الثاني

- لا تحتاج إلى مجلد هوية جاهز. ابدأ بهوية موجودة، أو بعض المراجع، أو أجب عن أسئلة قصيرة لتحديد الاتجاه.
- يقترح المساعد اتجاهين إلى أربعة اتجاهات بصرية مع الألوان والخطوط والمبررات، ويحفظ اختيارك لكل علامة.
- تبدأ التجربة بعينة صغيرة فعلية قبل إنتاج دفعة كاملة، وتحفظ الملاحظات المعتمدة للاستفادة منها لاحقًا.
- تعتمد الكتابة على موقف واضح وفكرة مفيدة وأدلة، ويتغير التكوين والإيقاع حسب الموضوع مع الحفاظ على الهوية.
- أصبحت اللوحة أبسط: اليوم، مراجعة المنشورات، النشر، النتائج. أدوات الهوية والخطط والتعلم موجودة تحت «More tools».
- تعرض المراجعة منشورًا واحدًا، مع التنقل بين الشرائح واختيار نص كل منصة، ثم الموافقة أو طلب تعديل محدد.

واجهة اللوحة بالإنجليزية، وتعرض النصوص العربية باتجاهها المناسب. جودة الإنتاج تعتمد على نموذج المساعد وأدوات التصميم والتصيير المتاحة؛ لا تتضمن الإضافة خدمات مدفوعة أو رصيد توليد.

للترقية: أوقف اللوحة، انسخ مساحة العمل احتياطيًا، حدّث الإضافة ثم افتح المجلد ومعرّف العلامة نفسيهما. ملفات الإصدار الأول تبقى صالحة. اختيار اتجاه بصري جديد يتطلب مراجعة الهوية مجددًا.

## ما الذي تقدمه الإضافة؟

| المرحلة | الوظيفة |
| :--- | :--- |
| فهم العلامة | استبيان قابل للاستكمال، جمهور، أهداف، أسلوب كتابة وأصول بصرية |
| الذاكرة | ملفات منفصلة للعلامات وقواعد معتمدة وملاحظات محددة النطاق |
| التخطيط | استراتيجية شهرية ومحاور محتوى ومواعيد مرتبطة بالمنطقة الزمنية |
| الإنتاج | إرشادات للكتابة والصور والمنشورات متعددة الشرائح والفيديو |
| المراجعة | لوحة محلية لمعاينة الملفات وتسجيل الملاحظات والموافقة |
| التسليم | تصدير يدوي أو إرسال اختياري عبر Postiz بعد تأكيد صريح |
| التعلم | سجلات مؤشرات موثقة وقواعد مستخلصة من ملاحظات المالك بعد موافقته |

**هذا الإصدار إضافة محلية، وليس خدمة مستضافة أو روبوت نشر تلقائي.**
ينفذ نموذج الذكاء الاصطناعي في التطبيق العمل الإبداعي. تحتاج الصور والفيديو إلى أدوات
إنتاج أو تصيير متاحة. لا تتضمن الإضافة اشتراكًا في نموذج أو رصيدًا للخدمات الخارجية.

## أول استخدام

اطلب من المساعد:

> استخدم Social Media Engine لإعداد علامتي. مجلد العمل هو [مجلد خاص بك].
> اسألني أسئلة التعريف، وراجع ملفات الهوية، واطلب موافقتي قبل إنتاج المحتوى.

1. عرّف النشاط والعروض والجمهور والأسواق واللغات والأهداف.
2. أضف ملفات الهوية والشعار والخطوط المرخصة والأمثلة والأساليب الممنوعة.
3. راجع ملخص العلامة واعتمده. تحفظ الإجابات تدريجيًا ويمكن استكمالها لاحقًا.
4. اختر أدوات الإنتاج والتسليم. Postiz اختياري، والتصدير اليدوي متاح.
5. اطلب 1 إلى 3 نماذج، بينها منشور متعدد الشرائح وفيديو إذا كانت الأدوات متاحة.
6. راجع الملفات الفعلية، وقدّم ملاحظات محددة، واعتمد القواعد التي تريد استمرارها.

لا تفترض الإضافة لهجة عربية معينة. تحدد أنت اللهجة والنبرة واللغات.
لكل علامة معرّف مستقل، ولا ينبغي خلط معلومات العلامات.

## لوحة المراجعة

اطلب فتح اللوحة، أو نفذ الأمر التالي من نسخة المستودع:

</div>

```sh
python3 plugins/social-media-engine/scripts/sme.py \
  --workspace "/absolute/path/to/private-workspace" \
  --brand your-brand dashboard
```

<div dir="rtl">

افتح الرابط الخاص الذي يظهر على الجهاز نفسه واترك العملية تعمل. استخدم Ctrl+C
للإيقاف. تتضمن اللوحة الهوية والأصول وخطط المحتوى ومعاينات الملفات والملاحظات
والموافقات وسجلات الإرسال والأدلة. واجهة اللوحة الحالية باللغة الإنجليزية.

ترتبط اللوحة بالعنوان المحلي 127.0.0.1 وتستخدم رمز جلسة عشوائيًا. لا تنشر الرابط
ولا تعرض الخادم للإنترنت. هذه ليست خدمة آمنة متعددة المستخدمين.

## النشر عبر Postiz

هيئ بيانات خدمتك الخاصة في بيئة التنفيذ، وليس داخل المحادثة:

</div>

```text
POSTIZ_API_URL=https://your-postiz-instance.example/api/public/v1
POSTIZ_API_KEY=your-private-key
```

<div dir="rtl">

استخدم عنوان واجهة API العامة الفعلي لخدمتك مع أي بادئة لمسار الوكيل.
هذه أمثلة وليست بيانات اتصال فعلية. لا تقرأ الإضافة ملفات البيئة تلقائيًا.
تتحقق من الحسابات المتصلة، ثم تجهز عملية مرتبطة بالمحتوى والحساب والوقت.
يتطلب الإرسال موافقة صريحة وخياري الأمان التاليين، حتى لإنشاء مسودة بعيدة:

</div>

```text
--send
SOCIAL_ENGINE_ALLOW_PUBLISH=true
```

<div dir="rtl">

الاستجابة الناجحة للإرسال لا تثبت أن المنشور أصبح عامًا. عند غموض النتيجة،
تحقق من حالة المزود بدلًا من إعادة المحاولة تلقائيًا. إلغاء عملية محلية لا يلغي
منشورًا أو جدولًا لدى Postiz. قد يتطلب وضع الرفع في TikTok إكمال النشر داخل التطبيق.

إنستغرام وفيسبوك وTikTok أهداف أساسية، لكن الدعم الفعلي يعتمد على الحساب
والمزود والصيغة والصلاحيات. لا تتضمن الإضافة صندوق رسائل موحدًا لكل الشبكات.
تحتاج التعليقات والرسائل والتحليلات إلى مصادر وصلاحيات متاحة فعلًا.

## الجديد في الإصدار 2.1: مواد حقيقية للتصميم

يبحث المساعد عن صور فوتوغرافية وأيقونات ورسوم وخامات وأنماط وخطوط تناسب فكرة
المنشور وهوية العلامة، ثم يدمجها في تصميم أصلي قابل للتعديل. لا يعتمد المسار على
توليد صورة كاملة بالذكاء الاصطناعي لكل منشور.

- بحث مباشر من «Design library» في Openverse وWikimedia Commons وIconify ومجموعة Met.
- مكتبات متخصصة عبر متصفح المساعد: ambientCG وPoly Haven وHero Patterns وunDraw
  وSVG Repo وPexels وUnsplash وGoogle Fonts، مع إمكانية استخدام مصادر أخرى.
- تنزيل الملفات بعد فحص المصدر والترخيص، أو استيراد ملف نُزّل بإذن المستخدم.
- حفظ المواد لكل علامة بشكل منفصل، دون إلغاء اعتماد الهوية عند إضافة خامة جديدة.
- ربط المواد المستخدمة بالمنشور، وحفظ المصدر وصاحب العمل والترخيص والتعديلات.
  يُدرج الإسناد المطلوب في نصوص المنشورات، ويشمل التصدير ملف CREDITS.md.

البحث المدمج لا يحتاج مفتاح API. المكتبات الأخرى تعتمد على أدوات المتصفح المتاحة،
والمواد المدفوعة تحتاج ترخيص المستخدم وإذنه. نتائج البحث ليست تصريحًا تلقائيًا
بالاستخدام؛ يجب فحص المصدر والشروط والصورة الفعلية قبل اعتمادها. يدعم التنزيل صور
PNG وJPEG وWebP وSVG ثابتة وملفات الخطوط TTF وOTF وWOFF وWOFF2، بحد 20 ميغابايت
للملف و2 ميغابايت لملف SVG.

مثال: «ابحث عن صور حقيقية وخامات هادئة تناسب أسلوب هذا المنشور، وادمجها في تصميم
قابل للتعديل، واحفظ حقوق المصادر، ثم أرني النتيجة النهائية».
