# Compose from the message

Read only the relevant entries in [original pattern guidance](../assets/design-patterns.json).
These eight patterns are original working hypotheses, not proven recipes or a new tranche
of the visual study. Upstream provenance describes workflow influences; it does not imply
those projects endorsed these social compositions. Fictional examples are not claims to
reuse. No source artwork, fonts, palettes or empirical performance records are bundled.

For compact local retrieval, run Python 3.10+ with `../../scripts/design_patterns.py`
relative to the installed SKILL.md directory. This standalone helper is not an `sme.py`
subcommand and does not read a brand workspace or contact a service:

```sh
python3 /resolved/plugin/scripts/design_patterns.py --intent compare --format carousel
python3 /resolved/plugin/scripts/design_patterns.py --id one-scene-one-feeling
```

Available intents: `reveal`, `explain`, `compare`, `choose`, `demonstrate`, `evoke`,
`prove`, `invite`, `announce`, `teach`, `tell-story`, `entertain`.
Formats: `image`, `carousel`, `story`, `video`. No filters returns all eight entries;
multiple filters intersect. Unknown tags are errors; zero matches means no guidance for
that combination, not a production failure. Retrieval is exact matching, not an AI
recommendation or quality ranking. Read JSON directly if command execution is unavailable.

## Make a small composition contract

After reading the approved brand context and evidence, write a short production note in
the selected workspace (link it from the brief; do not add undocumented runtime fields):

- **Audience moment and payoff:** what this particular viewer notices, understands or
  feels before any CTA; what evidence or meaningful scene supplies it.
- **Pattern or original alternative:** one applicable pattern, its disqualifying condition,
  and why the current material passes that condition. A pattern is optional when none fits.
- **Reading order:** name the actual first, second and third elements, their relative
  size and placement; for a sequence, state what each frame adds. Sketch with real copy,
  not “headline here.” Decide the crop around the subject's meaningful detail.
- **Brand translation:** approved type roles, colors, image treatment, voice, mark clear
  space and script direction; identify the flexible axis, such as subject scale or pacing.
  Do not replace a brand's identity with a pattern's fictional example.
- **Material gaps and proof boundary:** which exact assets support which claims; which
  requirements need sourcing or owner input. Label demonstrations and provisional facts.
- **Visible acceptance check:** what someone must be able to see in the export, such as
  the comparison difference or readable event date, plus the pattern's `check` question.

Choose a composition because it expresses the message. A style word alone is not a plan.
Inspect the actual image before committing text placement; the usable negative space and
subject boundaries may require changing the sketch. Never generate a false artifact to
make the chosen layout possible. If the material disproves the plan, change the plan.

## Vary structure without losing identity

Within one series, retain useful anchors (type roles, alignment logic, mark treatment)
and vary the information-bearing parts: scale, viewpoint, evidence arrangement and
sequence. Across brands, compare hidden-logo thumbnails: identical subject size, headline
placement and footer can reveal an unexamined scaffold. A shared format is not inherently
wrong; justify it from each message and approved identity instead of forcing novelty.

“Better” contrasts repair a specific failure; they are not universally attractive layouts.
A sensory campaign can need no explanatory diagram; a technical claim can need less mood
and more evidence. After composing, use the [producer revision loop](producer-revision-loop.md)
and the existing independent reviews. Pattern selection never establishes quality.
